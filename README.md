# CampusEase – One Smart Campus Platform

**One Campus. One Platform. Zero Unnecessary Queues.**

## 📌 About the Project

CampusEase is a smart campus management platform designed to simplify everyday campus activities for students, faculty members, administrators, and maintenance staff.

It brings essential campus services together in one digital platform, reducing paperwork, unnecessary queues, and communication gaps.

## 🎯 Problem Statement

Students and administrators often face difficulties managing everyday campus activities, such as standing in long queues, reporting maintenance issues, finding classrooms, managing leave requests, and accessing important information.

CampusEase aims to solve these problems through a centralized digital platform.

## ✨ Key Features

- **Student Dashboard:** Access important academic and campus information.
- **Digital Queue Management:** Generate digital tokens and check queue status without standing in long queues.
- **Report a Problem:** Submit and track campus maintenance complaints.
- **Digital Leave Management:** Apply for leave and manage requests online.
- **Campus Navigation:** Find classrooms and important campus locations.
- **AI Assistant:** Get assistance with campus-related queries.
- **Faculty Dashboard:** Manage academic activities and student information.
- **Admin Dashboard:** Manage users, digital queues, and campus services.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd CampusEase
```

### 3. Install Dependencies

Navigate to the backend folder:

```bash
cd backend
npm install
```

### 4. Configure the Database

- Create a MySQL database.
- Configure your database credentials.
- Set up the required tables.
- Keep credentials in environment variables rather than uploading passwords.

### 5. Start the Backend

```bash
node server.js
```

### 6. Run the Frontend

Open the frontend `index.html` file in your browser.
